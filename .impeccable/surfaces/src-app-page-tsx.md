# Surface Brief: TechTracker Web Workspace

- **Scope & Mode:** Operate (authenticated BSIT Pre-OJT monitoring & computer laboratory inspection application across `01W–16W`).
- **Audience & Job:** ACLC College of Mandaue incoming fourth-year BSIT students, Pre-OJT coordinators (Admins), and SuperAdmin recording/verifying 100-hour duty attendance, technical task completion, and workstation conditions.
- **Unresolved Decisions:** Visual world replaced via Impeccable direction roll (assigned: Blueprint Ledger). Code-led build.

## Direction contract

- **THESIS:** The category standard executed impeccably — clean, fast, precise product UI at Linear / Notion / GitHub craft level, refusing decoration in favor of alignment, spacing, and a real type scale.
- **OWN-WORLD:** Canon: Plus Jakarta Sans + JetBrains Mono, cobalt primary on slate rail, off-white canvas, sharp 4px corners, no decorative gradients or glassmorphism, semantic status pills with non-color indicators (emerald credited/functioning, amber pending/maintenance, crimson rejected/repair).
- **STORY:** On arrival or sign-in, each role immediately sees its authorized operational state — students see pending vs. credited progress toward 100 hours and active tasks; coordinators see review queues and room defects; SuperAdmin sees executive oversight and escalations (no chat).
- **FIRST VIEWPORT:** Role-aware persistent navigation rail (bottom bar + drawer on mobile `430px`, left sidebar on desktop `1440px`), top page header with title, single primary action and notification bell, then the dual-segment 100-Hour Duty Ledger strip (pending vs. credited) or coordinator review queue table.
- **FORM:** Canon (category standard), `seed: none (pinned)` — user chose the standing exit at Linear / Notion / GitHub craft bar.
- **FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
